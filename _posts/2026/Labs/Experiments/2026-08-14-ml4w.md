지난번에는 hyde-project를 사용해봤었는데 업데이트에 오류도 많고 불안정한 부분이 많은 것 같아서 다른 걸로
갈아타기로 했다.

자료를 찾아보던 중 안정성과 디자인 모두를 만족하는 dotfiles인 ml4w를 찾게 되었다.
아마 큰 문제가 없으면 이걸 계속 쓸 것 같다.

## 1. USB 장치 만들기

[ml4w live iso](https://ml4w.com/os/) 여기서 live iso를 받아주자.
그리고 이걸로 usb 부팅장치를 만들어 준다.

## 2. USB 부팅

위에서 만든 부팅 가능한 USB로 부팅을 한다. 
부팅 시 BIOS 진입 키를 눌러서 부팅 메뉴에 진입할 수 있다.

## 3. 설치

```text
user : liveuser
passwd : liveuser
```
로 로그인하고 다음 명령어를 실행해 설치할 수 있다.

```bash
sudo install-ml4w-os
```

타임존 선택이랑 locale 선택이 나오는데 타임존은 Seoul로 하고 locale은 en_us로 하자.

설치할 디스크는 본인이 원하는걸로..

마지막 설치하기 전에 확인해야할 것이 있는데
BIOS로 표시되는지, UEFI로 표시되는지 잘 확인하자. 

반드시 UEFI로 표시되어 있어야한다!!

## 4.  환경 세팅

진행하면서 패키지 빌드 어떻게 할 것인지 선택하라고 묻는게 나올 수 있는데 전부 A, N으로 한다.

### 1. HyprMod

처음 부팅하면 welcome 창이 뜰 텐데 거기서 settings->HyprMod를 클릭해서 설치한다.
hyprland의 설정을 gui 형태로 조작할 수 있게 해주는 유용한 도구다.

### 2. zsh
똑같이 welcome에서 system->change shell로 쉘을 zsh로 바꾼다. 이 설정은 바로 적용되는게 아니라 재부팅해야 적용된다.

재부팅 했다면 ~/.zshrc_custom 파일을 만들어서 원하는 설정을 추가할 수 있다.

```bash
alias ls='eza --icons=always'
export EDITOR="code"
eval "$(zoxide init zsh)"
ZSH_AUTOSUGGEST_HIGHLIGHT_STYLE='fg=#666666'

export GEM_HOME="$(ruby -e 'puts Gem.user_dir')"
export PATH="$PATH:$GEM_HOME/bin"
```

폰트가 너무 작거나 한 경우에는 `~/.config/kitty/kitty.conf` 파일의 font_size 값을 조절할 수 있다.

### 13. os-prober & grub theme

[grub tela theme](https://www.gnome-look.org/p/1307852) 에서 해상도에 맞는 파일 다운로드, /boot/grub/themes/ 디렉토리에 압축해제(루트 권한 필요)
```bash
sudo nano /etc/default/grub
```

```txt
GRUB_THEME="/boot/grub/themes/Tela-1080p/Tela/theme.txt"
```
GRUB_THEME 부분 찾아서 주석 제거하고 경로 설정

```bash
sudo pacman -S os-prober
sudo nano /usr/bin/grub-mkconfig
```

```txt
GRUB_DISABLE_OS_PROBER="false"
```
해당 항목 찾아서 false로 변경

```bash
update-grub
```
명령어 입력 이후 재부팅

### 14. 카카오톡

[카카오톡 설치 방법](https://strcur.tistory.com/183) 
이 링크의 방법을 따라하되, /etc/environment에 환경변수 설정은 굳이 안해도 된다.
대신 bottles의 설정에서 xwayland 설정을 켜준다.
그리고 러너는 해당 깃헙가서 제일 최신걸로 가져와서 해주자.
레지스트리는 root로 바꾸는거 하지말고

```text
HKCU\Software\Wine\Explorer
    ShowSystray = 0 (DWORD)

HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer
    NoTrayItemsDisplay = 1 (DWORD)
```

이렇게 바꾼다.

의존성 설치하는 과정에서 뭐 실패 뜰 수도 있는데 그냥 무시하고 해보니까 잘 된다.
그리고 desktop 엔트리 추가하는거에서 뭐 터미널에 붙여넣으라고 뜰 수 있는데, 그거 붙여넣고 bottles 종료 후 재시작하고 다시 엔트리에 추가하면 된다.
