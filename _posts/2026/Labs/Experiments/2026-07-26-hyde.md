hyprland를 써보고 싶어서 dotfiles 중 괜찮은걸 찾던 중 HyDE-Project를 알게되었는데 좋은 것 같아서 설치해보기로 했다.

## 1. HyDE 설치

```bash
sudo pacman -S --needed git base-devel
git clone --depth 1 https://github.com/HyDE-Project/HyDE ~/HyDE
cd ~/HyDE/Scripts
./install.sh
```

스크립트를 실행하면 자동으로 설치가 시작된다.
중간에 옵션 선택하라고 하면 전부 1번 하면 된다.
그리고 패키지 설치를 위해 비밀번호를 요구하면 입력하면 된다.

설치가 다 된다면 재부팅하자.

## 2. HyDE 세팅

### 2.1 모니터 세팅

`window + a`로 rofi 열어서 디스플레이 설정에 들어가서 모니터에 맞게 값을 조정해주자.

```bash
code ~/.config/hypr/monitors.conf  
```
모니터 설정을 열어서 본인의 모니터에 맞게 설정하자. 모니터가 하나라면 이 과정은 건너뛰어도 된다.
```
monitor=HDMI-A-1,1920x1080@60.0,840x0,1.0
monitor=HDMI-A-1,transform,3
monitor=DP-3,2560x1440@180.0,1920x0,1.25


# 메인 모니터
workspace = 1, monitor:DP-3, default:true
workspace = 2, monitor:DP-3
workspace = 3, monitor:DP-3
workspace = 4, monitor:DP-3
workspace = 5, monitor:DP-3

# 왼쪽 모니터
workspace = 6, monitor:HDMI-A-1, default:true
workspace = 7, monitor:HDMI-A-1
workspace = 8, monitor:HDMI-A-1
workspace = 9, monitor:HDMI-A-1
workspace = 10, monitor:HDMI-A-1
```

```bash

   ~/.config/waybar/layouts/dp3-only.jsonc
```

## 3. 기본 환경 세팅

### 3.1 한글 폰트 및 입력기 설치

```bash
sudo pacman -Syu --needed \
    fcitx5 \
    fcitx5-hangul \
    fcitx5-configtool \
    fcitx5-gtk \
    fcitx5-qt \
    noto-fonts \
    noto-fonts-cjk \
    noto-fonts-emoji

fc-cache -fv

sudo sed -i -E \
  -e 's/^# *en_US\.UTF-8 UTF-8/en_US.UTF-8 UTF-8/' \
  -e 's/^# *ko_KR\.UTF-8 UTF-8/ko_KR.UTF-8 UTF-8/' \
  /etc/locale.gen

sudo locale-gen
nano ~/.config/hypr/hyprland.conf
```

아래 내용 추가 후 재부팅

```
# Fcitx5 Korean input
env = XMODIFIERS,@im=fcitx
env = GTK_IM_MODULE,fcitx
env = QT_IM_MODULE,fcitx
env = QT_IM_MODULES,wayland;fcitx;ibus
env = SDL_IM_MODULE,fcitx
env = GLFW_IM_MODULE,ibus

exec-once = fcitx5 -d
```

```bash
pgrep -a fcitx5 #확인
fcitx5-configtool
#input method 에 hangul 검색 후 추가
#global options에서 trigger input method 한영키 클릭
```
