네트워크 관리사 2급 2022.08.21 필기 정리

## 프로토콜

1. 캡슐화 : 사용자 정보에 헤더와 트레일러를 추가하여 네트워크를 통해 전송할 수 있도록 준비하는 프로세스. 헤더에는 소스 및 대상 IP 주소와 같은 정보가 포함되어 있고 트레일러에는 데이터가 올바르게 수신되었는지 확인하기 위한 오류 검사 정보가 포함되어 있다. 이 프로세스는 네트워크를 통해 데이터가 정확하고 효율적으로 전송되도록 보장한다.

2. 동기화 - 동기화는 네트워크의 다른 장치 간에 전송 타이밍을 조정하는 프로세스를 말한다. 이는 데이터가 올바른 순서로 전송되고 장치가 효과적으로 통신할 수 있도록 보장하는 데 중요하다.

3. 다중화 : 다중화는 네트워크를 통해 전송하기 위해 여러 데이터 스트림을 하나의 데이터 스트림으로 결합하는 프로세스를 말한다. 이는 종종 네트워크 전송의 효율성을 높이고 여러 장치가 단일 네트워크 연결을 공유할 수 있도록 하기 위해 사용된다.

4. 주소지정 : 주소지정은 IP 주소 또는 MAC주소와 같은 네트워크 장치에 고유 식별자를 할당하는 프로세스를 말한다. 이는 장치가 서로 통신하고 데이터가 네트워크를 통해 올바르게 라우팅 되도록 하기 위해 필요하다.

## ARQ
| 보기                     | 설명                        |
| ---------------------- | ------------------------- |
| ① Adaptive ARQ         | 회선 상태에 따라 프레임 길이 변경       |
| ② Go-back-N ARQ        | 오류 발생 시 해당 프레임 이후를 모두 재전송 |
| ③ Selective-Repeat ARQ | 오류 난 프레임만 선택적으로 재전송       |
| ④ Stop and Wait ARQ    | 한 프레임 보내고 ACK 기다림         |


## Multiplexing

TDM(시분할 멀티플렉서) : 채널을 동일한 시간 슬롯으로 나누고 각 시간 슬롯은 고정된 시간 동안 특정 신호에 할당됩니다. 신호는 할당된 시간 간격 동안 교대로 전송된다.

STDM(통계 시분할 다중화) : 대역폭 요구 사항에 따라 신호에 시간 슬롯을 동적으로 할당하는 알고리즘을 사용한다. 더 많은 대역폭에 필요한 신호에는 더 많은 시간 슬롯이 제공되는 반면, 대역폭 요구사항이 적은 신호에는 더 적은 시간 슬롯이 제공된다.

FDM(주파수 분할 다중화) : 채널을 서로 다른 주파수 대역으로 나누고 각 신호는 특정 주파수 대역에 할당된다. 신호가 서로 다른 주파수 범위를 사용하기 때문에 동일한 채널을 통해 동시에 전송된다.

FDMA(주파수 분할 다중 액세스) : 무선 통신 시스템에서 사용되며 사용 가능한 주파수 범위를 여러 채널로 나눈다. 각 채널은 통신세션 동안 해당 채널을 독점적으로 사용하는 특정 사용자에게 할당된다. 이를 통해 여러 사용자가 동시에 동일한 통신 채널에 액세스할 수 있지만 각 사용자는 고유한 전용 주파수 범위를 가진다.

## chage

| 옵션        | 의미                            | 예시                          |
| --------- | ----------------------------- | --------------------------- |
| `-l`      | 현재 비밀번호 만료 정보 확인              | `chage -l user1`            |
| `-m DAYS` | 비밀번호 변경 후 다시 변경 가능해지기까지 최소 일수 | `chage -m 1 user1`          |
| `-M DAYS` | 비밀번호 최대 사용 가능 일수              | `chage -M 90 user1`         |
| `-W DAYS` | 만료 전 경고 메시지를 보여줄 일수           | `chage -W 7 user1`          |
| `-I DAYS` | 비밀번호 만료 후 계정 비활성화까지의 유예 기간    | `chage -I 10 user1`         |
| `-E DATE` | 계정 만료 날짜 설정                   | `chage -E 2026-12-31 user1` |
| `-d DATE` | 마지막 비밀번호 변경 날짜 설정             | `chage -d 0 user1`          |

## TPM(Trusted Platform Module)

보안 암호화 프로세서를 위한 국제 표준, 하드웨어를 보호하는 전용 마이크로 컨트롤러. 고속 데이터 암호화 및 해독이 가능하며 BIOS 및 운영체제가 수정되지 않도록 보호하는 보조 프로세서 (칩이다. 칩은 BIOS에서 설정)
BitLocker 기능을 사용하려면 메인보드와 BIOS에서 해당 기능을 지원해야한다.

## RAID

RAID 0 - 이 구성에는 스트라이핑이 있지만 데이터의 중복은 없습니다. 최상의 성능을 제공하지만 내결함성은 제공하지 않는다.
RAID 1 - 디스크 미러링이라고도 하는 이 구성은 데이터 저장소를 복제하는 두 개 이상의 드라이브로 구성된다.
RAID 2 - RAID2는 RAID 0처럼 스트라이핑 구성이지만 일부 디스크에는 오류 검사 및 수정을 위해 ECC(Error Correction Code) 정보가 저장된다.
RAID 3 - RAID 3 구성은 스트라이핑을 사용하고 하나의 드라이브를 패리티 정보를 저장하는데 사용

## 라우팅

라우팅 구분은 크게 2가지로 거리벡터 라우팅과 링크 상태 라우팅으로 나눈다.
거리벡터 라우팅의 경로 알고리즘은 벨만-포드(Bellman-Ford)알고리즘이며 대표적 프로토콜로는 RIP, IGRP, BGP 등이 있다.
반면 링크 상태 라우팅의 경로 알고리즘은 다익스트라(Dijkstra)알고리즘이며 대표적 프로토콜로 OSPF, EIGRP 등이 있다.
