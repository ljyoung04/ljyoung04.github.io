바이너리 분석을 편하게 하기 위해 Ai가 ida를 사용할 수 있도록 mcp를 구성해보자.

나는 wsl2에서 codex를 사용하고 있고, ida mcp는 호스트에서 돌아가고 있다.

## 1. wsl config

윈도우 호스트에서 수행한다.

`~\.wslconfig`에 다음 내용을 추가하자. 없다면 파일을 생성하자.

```text
[wsl2]
networkingMode = mirrored
```

호스트와 같은 ip를 사용하게 한다.

이후 파워쉘을 관리자 권한으로 실행해서 다음 명령을 실행한다.

```powershell
wsl --shutdown
```

## 2. IDA MCP

윈도우 호스트에서 수행한다.

```powershell
pip install https://github.com/mrexodia/ida-pro-mcp/archive/refs/heads/main.zip
ida-pro-mcp --install
```

이후 IDA로 바이너리를 열고 MCP를 활성화한다.
(Edit -> Plugins -> MCP)

그러면 아래쪽 콘솔에 다음과 같은 출력이 있을 것이다.

```text
[MCP] Server started:
  Streamable HTTP: http://127.0.0.1:13337/mcp
  SSE: http://127.0.0.1:13337/sse
  Config: http://127.0.0.1:13337/config.html
```
이걸 기억해두자.

## 3. codex config

wsl2에서 수행한다.

`~/.codex/config.toml`에 다음 내용을 추가한다.

```toml
[mcp_servers.ida]
url = "http://127.0.0.1:13337/mcp"
enabled = true
startup_timeout_sec = 15
tool_timeout_sec = 60
```

그리고 codex를 열어서 /mcp로 확인한다.

```text
/mcp

🔌  MCP Tools

  • codex_apps
    • Auth: Bearer token
    • Tools: (none)

  • ida
    • Auth: Unsupported
    • Tools: basic_blocks, callees, callgraph, declare_stack, declare_type, decompile, define_code,
    define_func, delete_stack, disasm, export_funcs, find, find_bytes, find_regex, get_bytes,
    get_global_value, get_int, get_string, imports, infer_types, int_convert, list_funcs, list_globals,
    lookup_funcs, patch, patch_asm, put_int, py_eval, read_struct, rename, search_structs,
    set_comments, set_type, stack_frame, undefine, xrefs_to, xrefs_to_field
```
잘 잡혀있는 것을 확인할 수 있다.
