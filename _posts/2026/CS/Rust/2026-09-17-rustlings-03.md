```rust
        assert_eq!(picky_eater("strawberry"), "Yummy!");
    }

    }
```

3개의 test함수를 모두 통과해야 한다.
일단 picky_eater의 else 부분이 1 이라 반환 타입이 안맞아서 컴파일 에러가 나기 때문에 바꿔줘야한다.
yummy_food의 경우는 자동으로 만족한다.
neutral_food의 경우 potato if 분기가 필요하다.
나머지 경우에는 "No thanks!"를 반환하게 하면 된다.

```rust
fn picky_eater(food: &str) -> &str {
    if food == "strawberry" {
        "Yummy!"
    } else if food == "potato" {
        "I guess I can eat that."
    } else{
        "No thanks!"
    }
}
```
