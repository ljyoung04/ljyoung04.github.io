러스트를 좀 공부해보고 싶어서 자료를 찾아보다가 Rustlings을 알게되었다. 이걸로 러스트에 대한 기초를 다져봐야겠다.

# 1. Rustup && Rustlings 설치

```bash
sudo pacman -S rustup

rustup default stable
rustup component add rust-analyzer rust-src clippy rustfmt

cargo install rustlings
rustlings init

cd rustlings
rustlings
```

# 2. 01_variables

## 1.

```rust
fn main() {
    // TODO: Add the missing keyword.
    x = 5;

    println!("x has the value {x}");
}
```

`x = 5` 부분이 잘못되었다. 변수를 선언할 때는 let 키워드를 사용하여 선언할 수 있다.

## 2.

```rust
fn main() {
    // TODO: Change the line below to fix the compiler error.
    let x;

    if x == 10 {
        println!("x is ten!");
    } else {
        println!("x is not ten!");
    }
}
```

변수가 초기화되어 있지 않다. `let x = 10` 이런 식으로 초기화해주자.

## 3.

```rust
fn main() {
    // TODO: Change the line below to fix the compiler error.
    let x: i32;

    println!("Number {x}");
}
```

이것도 변수가 초기화되어 있지 않다.

## 4.

```rust
// TODO: Fix the compiler error.
fn main() {
    let x = 3;
    println!("Number {x}");

    x = 5; // Don't change this line
    println!("Number {x}");
}
```

let으로 선언한 변수는 불변형이다. `let mut` 처럼 mut 키워드를 통해 가변형 변수로 선언해야한다.

## 5.

```rust
fn main() {
    let number = "T-H-R-E-E"; // Don't change this line
    println!("Spell a number: {number}");

    // TODO: Fix the compiler error by changing the line below without renaming the variable.
    number = 3;
    println!("Number plus two is: {}", number + 2);
}
```

처음에는 number가 &str인데, 3을 집어넣으려 해서 오류가 발생한다. `let number = 3` 처럼 재선언을 통해 해결할 수 있다.

## 6.

```rust
// TODO: Change the line below to fix the compiler error.
const NUMBER = 3;

fn main() {
    println!("Number: {NUMBER}");
}
```

const를 사용한 변수는 반드시 타입을 명시적으로 작성해줘야 한다. `const NUMBER : i32 = 3;`
