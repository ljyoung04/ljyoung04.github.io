러스트에서 배열을 다음과 같이 선언할 수 있다.

```rust
let arr = [1,2,3,4,5];
let arr : [i32, 5] = [1,2,3,4,5];
let arr = [0;5] // [타입, 길이] 예시와 같이 타입 부분에 특정 값을 넣는 것으로 같은 값으로만 이루어진 배열을 만들 수 있다.
```

## 4.

```rust
fn main() {
    // You can optionally experiment here.
}

#[cfg(test)]
mod tests {
    #[test]
    fn slice_out_of_array() {
        let a = [1, 2, 3, 4, 5];

        // TODO: Get a slice called `nice_slice` out of the array `a` so that the test passes.
        // let nice_slice = ???

        assert_eq!([2, 3, 4], nice_slice);
    }
}
```

a를 슬라이싱하여 nice_slice 배열을 만들면 된다.

러스트에서 배열의 슬라이싱은 다음과 같이 할 수 있다.

```rust
let arr = [1,2,3,4,5];
let tmp = &arr[0..3]; // [1,2,3]
```
슬라이싱할 때 [1..4] 이런 식으로 할 경우 4는 포함되지 않는다.
이를 포함하고자 한다면 ..= 를 사용할 수 있다.

슬라이싱은 데이터를 복사하는게 아닌 원본 배열을 참조하는 것이다.

따라서 슬라이스의 타입은 배열 타입과 다르다. 위 예시에서 arr은 i32고, tmp는 &[i32]이다.
