HTB를 통해 공부하던 중 pwnbox 시간이 너무 적은 것 같아서 그냥 로컬에서 vpn을 통해 접속하는 방법을 정리한 글이다.

![1](/assets/img/2026/htb-vpn/1.png)

왼쪽 위를 보면 Connect 버튼이 보이는데 눌러보자. 나는 지금 연결해놔서 저렇게 초록색이지만 연결해두지 않았으면 회색으로 표시될 것이다.

![2](/assets/img/2026/htb-vpn/2.png)

여기서 연결하고자 하는걸 클릭한다.
Starting Point를 예시로 하겠다.

![3](/assets/img/2026/htb-vpn/3.png)

OpenVPN 클릭

![4](/assets/img/2026/htb-vpn/4.png)

Download VPN을 클릭해서 파일을 다운받자.

이 파일과 Openvpn을 사용해서 접속할 수 있다.

```bash
sudo apt install openvpn
sudo openvpn <vpn 파일 명>
```

이렇게 연결해둔 터미널은 끄지 말고 다른 터미널을 열어서 작업하도록 하자.
